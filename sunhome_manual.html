第一次使用：設定雲端儲存
只需做一次，之後所有裝置都能同步
⚠️ 這個步驟很重要！如果跳過，只有您自己的電腦看得到更新，換台裝置就消失了。
前往 JSONBin 免費註冊

用瀏覽器開啟 https://jsonbin.io，點右上角「Sign Up」，用 Google 或 Email 免費註冊帳號。

建立一個新的 Bin

登入後點右上角「CREATE BIN」按鈕，在內容欄位貼上 {}，然後點「CREATE」儲存。

複製 Bin ID

建立後網址會變成 https://jsonbin.io/b/這串字就是BinID，複製那串英數字（例如：6673f9b4e41b4d34e4187abc）

取得 Master Key

點右上角頭像 → 「API Keys」→ 複製 Master Key（格式像 $2b$10$xxxx...）

填入管理面板

開啟網站 → 登入管理面板 → 找「☁️ 雲端儲存設定」區塊 → 填入 Bin ID 和 Master Key → 點「💾 儲存設定」

✅ 設定完成後，任何裝置開啟網站都會自動讀取雲端最新內容！

登入管理面板
每次更新前先登入
開啟網站

用瀏覽器開啟 https://sunhomeacademy.github.io/

點管理按鈕

頁面右上角有一個 管理網站 ⚙️ 按鈕，點一下。

輸入密碼

在彈出的登入框輸入密碼：sunhome2026，然後點「登入」或按 Enter。

管理面板從右側滑出

登入成功後右側會出現管理面板，可以開始操作。

🖥️ 畫面示意
右上角按鈕 → 彈出密碼視窗 → 輸入 sunhome2026 → 右側面板滑出 ✅
3
新增最新消息
加入新的宣傳圖片與標題
點「➕ 新增一則消息」

在管理面板的「最新消息管理」區塊，點藍色的新增按鈕，會出現一個新的空白欄位。

填入 Google Drive 圖片連結

先把圖片上傳到 Google Drive → 右鍵 → 「共用」→ 設為「知道連結的任何人可以檢視」→ 複製連結 → 貼入「Google Drive 圖片連結」欄位。

範例連結格式
https://drive.google.com/file/d/1ABCxxx.../view?usp=sharing
填入消息標題

在「消息標題」欄位輸入標題文字，例如：暑假先修班開始報名

填入消息內容（選填）

可以不填。如果要加說明文字，在「消息內容」欄位輸入即可。

點「💾 儲存並發佈」

完成後點最下方的綠色按鈕儲存，雲端同步成功後所有裝置立即看到新消息。

⚠️ Google Drive 圖片必須設為「知道連結的任何人可以檢視」，否則圖片無法在網站上顯示。
4
修改現有消息
更換圖片或修改標題文字
登入管理面板

依照第2節步驟登入。

找到要修改的消息

在「最新消息管理」區塊，每一則消息都有獨立的輸入框，找到要改的那一則。

直接修改欄位內容

點擊「Google Drive 圖片連結」或「消息標題」欄位，直接編輯文字即可。

點「💾 儲存並發佈」

修改完成後，點最下方綠色按鈕發佈更新。

5
刪除消息
移除過期的消息
找到要刪除的消息

在管理面板的「最新消息管理」區塊，找到要刪除的那則消息。

點「❌ 刪除此則」

點紅色刪除按鈕，該則消息會從列表消失。

點「💾 儲存並發佈」

一定要點儲存，否則刪除不會生效。

⚠️ 刪除後如果沒有點「儲存並發佈」，重新整理頁面後刪除的消息會回來。

7
儲存並發佈
每次修改後的最後一步
確認所有修改都完成了

新增、修改、刪除都做完後，才點儲存按鈕。

點「💾 儲存並發佈（同步至雲端）」

這個大綠色按鈕在管理面板最底部。

確認成功訊息

按鈕下方會出現訊息：

✅ 已成功同步至雲端！所有裝置將看到最新內容。
⚠️ 如果出現紅色訊息，代表 JSONBin 設定有問題，請重新確認 Bin ID 和 Master Key。
8
更新 GitHub 網頁檔案
當程式碼本身需要更新時才需要做
💡 一般更新最新消息、標題、電話，不需要重新上傳 GitHub。只有在需要改版網頁結構時才需要此步驟。
取得新的 HTML 檔案

下載最新版的 HTML 檔案，改名為 index.html。

登入 GitHub

開啟 https://github.com/sunhomeacademy → 進入 sunhomeacademy.github.io repository。

上傳新檔案

點「Add file」→「Upload files」→ 把 index.html 拖入 → 點「Commit changes」。

等待約 1 分鐘

GitHub Pages 自動部署，約 1 分鐘後網站即更新。用 Ctrl+Shift+R 強制重新整理確認。

9
常見問題 FAQ
遇到問題先看這裡
儲存後其他裝置還是看不到更新？
請確認 JSONBin 的 Bin ID 和 Master Key 有正確填入，且點了「💾 儲存設定」。也確認「儲存並發佈」有出現綠色成功訊息。
圖片不顯示，只看到標題？
Google Drive 圖片的共用設定需改為「知道連結的任何人可以檢視」，否則網站無法存取圖片。請重新設定共用權限後再試。
忘記管理員密碼怎麼辦？
目前密碼為 sunhome2026。如需更改密碼，請聯絡網站技術人員更新 HTML 檔案。
網頁一直在載入（轉圈圈）？
這通常是 JSONBin 連線逾時。若 5 秒內沒有讀取到雲端，會自動使用備用資料顯示。如果持續發生，請確認網路是否正常。
管理面板登入後是空的？
這是正常情況，代表雲端還沒有儲存任何資料。請直接新增消息後點「儲存並發佈」即可。
可以一次新增多則消息嗎？
可以！點多次「➕ 新增一則消息」，把所有消息都填好後，最後一次點「💾 儲存並發佈」就好，不需要每則分別儲存。
